# Examen Final – Predicción de Riesgo de Diabetes

Este proyecto implementa una arquitectura MLOps para predecir el riesgo de diabetes en pacientes mediante una API desarrollada con FastAPI y MongoDB Atlas como base de datos en la nube.

---

## 📦 Estructura del Proyecto

- `main.py`: API FastAPI para hacer predicciones.
- `train.py`: Script para entrenar el modelo.
- `modelo_entrenado.pkl`: Modelo serializado.
- `datos_diabetes.csv`: Dataset de entrenamiento.
- `requirements.txt`: Dependencias del entorno.
- `dvc.yaml`: Pipeline automatizado con DVC.
